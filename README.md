# Banking_Management_System

This program is a simple simulation of online banking <br>
The code demonstrates the use of structures, dynamic memory allocation, singly linked list t ostore the data of a customer and use of a stack to store the recent transactions <br>
Initially compile the code and run the .exe file <br>
You will get options to create a new account or login if you already have a account<br>
Initially create a new account and enter the requested information (Create multiple accounts for better use)<br>
Once the account is created note the account number and customer ID for further use<br>
You will get options like Deposit Money, Withdraw Money, Transfer Money, Account Details, Balance Enquiry and Mini statement<br>
